# spec/ — Output Rendering Specifications

This folder contains rendering specifications only.
How to structure and format output documents.

What belongs here:
  How a document is structured (section order, field format, labels)
  Schema definitions for machine-readable outputs
  Comparables table format
  Market positioning and landing page copy

What does NOT belong here:
  Investigation logic (goes in knowledge/)
  Vault-specific content (goes in packs/)
  Agent behaviour rules (goes in the core rules)
  Obsidian integration architecture (goes in knowledge/)
  Red flag rendering logic (goes in knowledge/)

Contents:
  d2-output-spec.md       — D2 IC Memo rendering specification
  d5-and-defi-teardown-spec.md — D5 interview framework + teardown format
  evidence-object-schema.md       — the structured evidence output API schema (primary output)
  gap-register-schema.md  — Gap register JSON schema
  comparables-spec.md     — Comparables table format
  market-positioning.md   — Market context and positioning
  landing-page-*.md       — Landing page copy variants
