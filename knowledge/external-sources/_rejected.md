# External Sources Registry — Rejected

Institutional memory of candidate sources evaluated and rejected, so the same
source is not re-evaluated repeatedly. Schema: `spec/external-sources-schema.md`.
Workflow: `.claude/skills/source-add/SKILL.md`.

One line per rejected candidate:

```
- <slug-or-url> | <date> | rejected: <one-sentence reason>
```

Common reasons: INFORMAL-only with no field needing an INFORMAL ceiling;
aggregator-of-aggregators below an existing source; maintainer abandoned;
methodology not published (tier unverifiable); redundant coverage with no
fallback value.
