# F-STD-007

**Field ID**: F-STD-007
**Category**: Party Standing
**Sub-Category**: Recency & Change
**Field Name**: Change Since Onboarding
**What to Collect / Question to Answer**: Has any yield-critical party's standing changed since the vault onboarded it — a credit downgrade, a merger or acquisition, a change of control, a regulatory action, or a key-personnel departure? Record each as a dated change-event with its source and the as-of-date of the check. Where a party is unchanged, record "no change since onboarding, as of [date]": silence is not a finding, but the check must be run and dated. This is the field the the CLO fund manager downgrade-plus-merger event (June 2026) would populate.
**Data Type**: Structured (party -> change-type -> description -> event date -> as-of-date -> source; or dated "no change")
**Vault Types**: ALL (assessed only for parties flagged yield-critical in F-STD-001; N/A for parties not so flagged)
**Collection Tier**: T2
**Pillar(s)**: P18
**Primary Source**: Rating-action releases, regulatory filings, and corporate announcements for the party, checked at assessment time against its status at vault onboarding
**Fallback Source**: Reputable news reporting of the change (corroborated to a filing or release); party disclosure
**Evidence Pathway**: Third-party-evidenced: compare each yield-critical party's current standing (F-STD-002 / 004 / 005 / 006) against its status at onboarding and record any downgrade / M&A / control change / regulatory action / key departure with its date and source.
**Institutional Standard**: A dated change-check has been run against each yield-critical party since onboarding, recording any change with its source and date, or an explicit dated "no change" where none is found.
**Status**: Gap with action
**If Not Found — Gap Action**: Change-check run and any change recorded and dated (or an explicit dated "no change"): E. Check run but a suspected change is unconfirmed: E(P), or I where sources conflict. A material change is known but its detail is restricted: G2. Change-check never run: a gap, not a clean result — state the action. Party not flagged yield-critical: N/A.
**Source / Precedent**: an internal analysis (2026-07-08): recency/change was the sharpest gap. Anchor event: S&P cut the CLO fund manager parent from BBB+ to BB on a buyout/merger into an acquirer on or about 30 June 2026, reflected in no a tokenized CLO fund fund document.
**Criterion ID(s)**: 18.7 (P18 Party Standing)
