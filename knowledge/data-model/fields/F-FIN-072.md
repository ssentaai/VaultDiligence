# F-FIN-072

**Field ID**: F-FIN-072
**Category**: Financial
**Sub-Category**: Yield Character
**Field Name**: Yield Obligation Type — Contractual vs Discretionary
**What to Collect / Question to Answer**: Is the underlying yield source a contractual payment (bond coupon, loan interest, fixed RWA coupon — issuer breaches if not paid) or a discretionary distribution (preferred equity dividend, governance reward — issuer can suspend without breach)? State which and cite source document.
**Data Type**: Text (Contractual / Discretionary / Mixed)
**Vault Types**: ALL
**Collection Tier**: T3
**Primary Source**: Issuer prospectus / preferred stock terms / subscription agreement / SEC filings
**Fallback Source**: Vault operator disclosure / governance forum RFC
**Pillar(s)**: P6
**D1**: Y
**D2**: Y
**D3**: Y
**D4**: Y
**D5**: Y
**Required?**: Y
**If Not Found — Gap Action**: Read issuer prospectus or preferred stock terms. Do not accept operator characterisation without verifying source document. a preferred-equity-backed vault: read the issuer's preferred-instrument prospectus — dividend formally discretionary.
