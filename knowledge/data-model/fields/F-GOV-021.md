# F-GOV-021

**Field ID**: F-GOV-021
**Category**: Governance
**Sub-Category**: Board Oversight
**Field Name**: Independent-Director Informational Capability / Board Oversight Cadence
**What to Collect / Question to Answer**: Can independent directors obtain and interrogate fund exposure, compliance status, and NAV-integrity data between meetings, and what is the cadence and anomaly-to-board-escalation lag — distinct from whether independent directors merely exist?
**Data Type**: Text (cadence) + Number (escalation lag, days/weeks) + Boolean (between-meeting data access)
**Vault Types**: Management=delegated-offchain-IM OR (Exposure in {equities,corporate-fixed-income,sovereign-fixed-income} AND venue=tradfi-primary)  (derived from VT-N; original "Vault Types" value: VT-3a, VT-8)
**Collection Tier**: T3
**Pillar(s)**: P1
**Primary Source**: Board charter / governance policy documenting director information rights and reporting cadence; board minutes evidencing between-meeting interrogation
**Fallback Source**: Operator disclosure of the board-pack cadence and any real-time oversight tooling (cite an ODD source Lex or equivalent as EXPERT and corroborate with prospectus/board minutes)
**Evidence Pathway**: Third-party-evidenced: obtain the board charter and a sample of board minutes showing the reporting cadence, whether directors can pull exposure/compliance/NAV data between meetings, and the documented lag from an anomaly arising to it reaching the board.
**Institutional Standard**: Good practice is independent directors with documented information rights and tooling to interrogate exposure, compliance status, and NAV integrity continuously or near-continuously, so an anomaly reaches the board within days; a quarterly board-pack model where the manager controls what is in the pack, how it is framed, and when it is provided leaves directors with stale information and no meaningful informational independence.
**Status**: Gap with action
**If Not Found — Gap Action**: Obtain the board charter and reporting cadence. Determine whether directors can access fund data between meetings and the documented anomaly-to-escalation lag. If only director existence is sourced (F-LEG-017) with no cadence or information-rights evidence: G2 — state that informational capability is unsourced and name the document required (board charter / minutes). If no between-meeting access exists: G3.
**Source / Precedent**: an ODD source AI-fund governance paper 2026: directors receive information four-to-six weeks old; a concentration breach in week five does not reach the board until week twelve — the manager controls what is in the board pack, how it is framed, and when it is provided. F-LEG-017 / RF27 / criterion 1.4 source director existence only, not informational capability.
**Criterion ID(s)**: 1.4, RF27
