# F-LIQ-042

**Field ID**: F-LIQ-042
**Category**: Liquidity
**Sub-Category**: Exit Liquidity Box
**Field Name**: OTC / Backup-Venue Contingency
**What to Collect / Question to Answer**: Does the operator maintain pre-arranged OTC liquidity or named backup venues for asset exits if the primary exchange or venue suffers an outage or delisting?
**Data Type**: Boolean + named OTC desks / backup venues + committed size and pre-arrangement evidence
**Vault Types**: ALL
**Collection Tier**: T2a
**Pillar(s)**: P9
**Primary Source**: Operator OTC / market-maker agreements; counterparty confirmation of a standing exit arrangement
**Fallback Source**: Operator disclosure naming the OTC desk or backup venue and stated committed size
**Evidence Pathway**: Third-party-evidenced: a named OTC desk or backup venue confirms a pre-arranged standing facility and its committed size; absence of any pre-arrangement makes the primary venue a single point of exit failure.
**Institutional Standard**: A pre-arranged OTC facility or named backup venue exists for exits during an exchange outage or delisting, with the counterparty and committed size stated. Venue concentration with no backup is a single-point exit failure and belongs in the Exit Liquidity Box.
**Status**: Gap with action
**If Not Found — Gap Action**: Confirm whether a pre-arranged OTC or backup-venue facility exists, name the counterparty, and state the committed size. If the operator relies on a single venue with no pre-arranged backup, state that as a single-point exit failure with the named venue. If the operator claims a backup but produces no counterparty confirmation, classify G2 and name the desk requiring confirmation.
**Source / Precedent**: Steakhouse Financial stablecoin-issuer DDQ v1.0 (§6.6): 'Do you maintain pre-arranged OTC liquidity or backup venues for asset exits in case of exchange outage or delistings?'
**Criterion ID(s)**: 9.1
