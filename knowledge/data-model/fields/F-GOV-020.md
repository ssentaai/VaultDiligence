# F-GOV-020 — Conflict of Interest Disclosure

**Field ID**: F-GOV-020
**Field Name**: Conflict of Interest Disclosure
**Pillar(s)**: P1
**Vault Types**: ALL
**Collection Tier**: T1
**Primary Source**: Protocol docs / Issuer disclosure
**D1**: N
**D2**: Y
**Required?**: Y
**TTL**: 4320h (180 days)

## Description

Has the curator or vault operator published a formal conflict of interest disclosure covering: entity relationships, token holdings in counterparty protocols, advisor relationships, and investor positions in allocated assets.

## Failure Mode

Undisclosed conflicts corrupt the independence of the vault governance. A curator allocating to protocols in which they hold tokens has a material financial interest in those allocations.

## If Not Found — Gap Action

Request formal conflict of interest policy from curator. Does curator hold positions in collateral assets it allocates to? Are advisors or team members investors in any counterparty protocol? Disclose or confirm none.
