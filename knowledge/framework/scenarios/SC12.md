# SC12 — Bridge pause / freeze on a route carrying vault exposure

## Scenario
A bridge or cross-chain messaging system on a route carrying vault exposure is paused — defensively (incident response) or because it has been exploited. Bridged representations on the affected chain become non-redeemable and non-transferable for the duration. A pause that stops an attacker is, for honest holders, an exit freeze: the same control protects and traps simultaneously.

## Trigger conditions (observable)
- A bridge authority or vendor invokes pause / halts verification on a route the vault depends on.
- A verifier-set compromise forces a defensive pause (cf. the Kelp 1-of-1 DVN failure mode).
- Rate limits set to zero (a legitimate issuer-side pause method) stop redemptions on the route.

## What to assess (evidence only)
1. How many independent pause pathways exist (issuer, vendor, protocol), and is reliance on a single path avoided? (F-BRG-006)
2. What is the measured detection-to-pause latency, and is there a 24/7 redphone across vendor, attestors, and issuer? (F-BRG-010)
3. Does a bridge incident socialise the loss across all holders, or fall only on holders on the affected chain? (F-LEG-018)
4. What is the holder's redemption path while the route is paused — is there a backup venue or OTC contingency? (F-LIQ-042)
5. Are bridge-authority changes (including un-pause) timelocked so a malicious un-pause can be observed? (F-BRG-005)

## Documented response expected
A response naming the pause pathways, who can un-pause and under what timelock, the expected holder experience during a pause, and the cross-chain loss-bearing hierarchy. If none exists: state the gap with a precise action.

## Cross-references
F-BRG-006, F-BRG-010, F-BRG-005; F-LEG-018; F-LIQ-042; RF44; P12.

## Precedent
Kelp DAO, 18 April 2026: a pauser froze the bridge 46 minutes after the drain began, blocking roughly $200M of follow-on theft — pause latency and pause authority set the loss boundary. The same pause left honest rsETH holders unable to move for the duration.
