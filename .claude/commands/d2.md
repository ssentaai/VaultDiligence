# D2 — Executive Summary

## Prerequisite

D1 must be complete. Load packs/{vault-slug}/D1-allocability-screen.md first.
If D1 hard gates were triggered and unresolved: state this at top of D2.

## Process

Step 1: Load D1 output and knowledge/framework/index.md.

Step 2: Run web search for any D2-specific fields not in D1.
  TradFi direct equivalent (F-MKT-003): web search + analyst judgment.
  Comparable vaults: web search for current TVL and APY of C1-C4 peers.
  Counterparty map: if not already built, run Agent 3 scope via web search.

Step 3: Calculate implied position size from Exit Liquidity Box.
  Use: max position at 1% slippage as ceiling.
  State explicitly: this is a liquidity-derived maximum, not a recommendation.

Step 4: For each of the six risk categories, state:
  - What was found (sourced facts)
  - What is not yet confirmed (open gaps)
  - Worst-case structural consequence at implied position size ($)
  This is not a verdict. It is a factual statement of evidence and gaps.

Step 5: Render D2 markdown to packs/{vault-slug}/D2-executive-summary.md
